# 读线 · PaperLine

[English](README.en.md) · 简体中文

一个本地运行的轻量论文阅读应用。用**阅读线**安排下一步，用**思想卡**汇集来自多篇论文的同一想法，用关系图查看论文如何提出、使用、改进或质疑它。

## 运行

需要 Python 3.10 或更新版本，无需安装依赖。

```bash
python3 app.py
```

应用会在浏览器打开 `http://127.0.0.1:8765`。macOS 也可以双击 `start.command`。关闭运行它的终端即可停止应用。

## 首次使用

1. 创建一条阅读线，写下要研究的问题。
2. 添加一张思想卡，例如 GRPO。卡片可以同时属于多条阅读线。
3. 在“论文库”搜索本机 Zotero，导入论文；也可以手动添加。选择论文后，可读取其文字批注并从批注建卡。
4. 把多篇论文关联到同一张卡，并为每条关系写下具体用法和原文位置。
5. 点击“开始读”，结束时用自己的话写两句。下次从同一张卡继续。
6. 在“设置”填写 Obsidian 库目录，点击“导出到 Obsidian”。

可以在设置中切换界面语言（简体中文 / English），也可以指定每日提醒时间。应用页面保持打开时会弹出站内提醒；按需开启浏览器通知。导出的 Obsidian 笔记标题会使用当前界面语言；已有笔记中手写的内容不会被改写。

Zotero 须保持开启，并在 **设置 → 高级**中启用“允许本机其他应用与 Zotero 通信”。应用只读取 Zotero 的本地接口，不修改 Zotero 资料。

## 数据与导出

- 应用数据存放在 `data/state.json`；该目录已被 Git 忽略。
- “设置 → 备份数据”可下载完整 JSON 备份。
- Obsidian 导出位置是所选库的 `PaperLine/`，包含“阅读线”“思想卡”“论文”三个目录。
- 重复导出只更新 `PAPERLINE:START/END` 标记之间的内容，保留标记之外的手写补充。如果同名文件没有标记，导出会停止，避免覆盖现有笔记。
- 论文笔记首次导出会带有你使用的“一句话、解决问题、核心机制、思考、技巧、局限”等栏目。

应用只绑定到 `127.0.0.1`，不需要账号或云服务。图谱和计时都在本机运行。
